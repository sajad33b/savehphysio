تنظیمات ذخیره (توکن گیت‌هاب)

برای ذخیره واقعی، یک‌بار باید Personal Access Token از گیت‌هاب بسازی و اینجا ذخیره کنی. توکن فقط روی همین مرورگر (localStorage) نگه داشته می‌شود و داخل سایت منتشر نمی‌شود.

توکن تنظیم نشده
نحوه ساخت توکن:
1. برو به GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate new token (classic)
3. فقط تیک repo را بزن
4. توکن را کپی کن و اینجا بچسبان
