    تنظیمات ذخیره (توکن گیت‌هاب)

    برای ذخیره واقعی، یک‌بار باید Personal Access Token از گیت‌هاب بسازی و اینجا ذخیره کنی.

    توکن تنظیم نشده
    GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → فقط تیک repo

    امنیت و تغییر رمز پنل

    برای تغییر رمز ورود، رمز فعلی و رمز جدید را وارد کن.

    رمز روی همین مرورگر ذخیره می‌شود. بعد از ورود حتماً رمز پیش‌فرض را عوض کن.
