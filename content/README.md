# content/

منبع محتوای قابل‌حمل سایت (جدا از قالب HTML).

## فایل‌ها
- `home.json` — سئو + محتوای صفحه اول

## بخش‌ها
- `seo` — title، description، canonical، Open Graph، کلمات کلیدی
- `content` — متن‌های قابل‌نمایش صفحه (هیرو، خدمات، FAQ، تماس، …)
- `meta` — نسخه و یادداشت فنی

## بعداً
- پنل ادمین می‌تواند همین JSON را بخواند/بنویسد
- هنگام مهاجرت به وردپرس، همین فیلدها به برگه/بلوک نگاشت می‌شوند

فعلاً قالب `index.html` هنوز مستقیماً به این فایل وصل نیست؛ فقط اسکلت آماده است.
